1. Unpin Microsoft Edge from Task Bar.
2. Open File Explorer and enable file extensions and pin FMEData to favourites.
3. Set Chrome to be default browser and pin to Task Bar.
4. Open FME Server and license it. Save username and password. Load FoodVendors-Complete.fsproject
5. Open FME Workbench and Data Inspector to ensure they are properly licensed, and pin them to Task Bar.
6. Add connections for FME Server (Training FME Server) and PostGIS (postgis.train.safe.com fmedata)
7. Add Stamen map to Workbench.
8. Open Localhost in browser, and ensure that FME Server is properly licensed.
9. Open Google Earth to see if it has a DirectX vs OpenGL warning. Set appropriately.
10. Run Ec2LaunchSettings. "Shutdown without Sysprep"
11. Create new AMI--leave Description blank. After the image is complete, edit the Description to `FME 20xx.x for Strigo`.
